## O que são Estruturas de Repetição e Iteração?

Significam a mesma coisas: são estruturas de programação que se repetem até a condição seja satisfeita, seja por repetição por vezes de algum número ou uma estrutura mais complexa usando boleano. 

### Quando são usadas?

* Para Buscar algo em alguma Lista
* Loops de condição

### Quais os principais tipos de estruturas de repetição

* While
* For
