## Código úteis

* pacote especifico: pip install nome_pacote
* versao especifica do pacote: pip nome_pacote==versão
* atualizar pacote: pip install --upgrade nome_pacote
* remover pacote: pip uninstall nome_pacote
* ver pacotes instalados: pip list
* detalhes pacote: pip show nome_pacote
* criar requirements: pip freeze > requirements.txt
* instalar requirements: pip install -r requirements.txt
